# Vale do Sol 🌱

Jogo de fazenda para navegador, com plantio, rega, colheita, loja e progresso salvo localmente.

## Jogar

GitHub Pages (após ativação): https://tomtelojk.github.io/asdsadsda/

## Desenvolvimento

Requer Node.js 18 ou superior.

```sh
npm ci
npm run dev
```

Use WASD ou as setas para caminhar, 1–5 para escolher ferramentas e clique nos canteiros. Regue as plantas e encerre o dia para fazê-las crescer.

```sh
npm run build
```

## Publicação

Em Settings → Pages, escolha **Deploy from a branch**, branch **main**, pasta **/ (root)** e salve. Os arquivos da raiz também funcionam como site estático, sem build no servidor.
